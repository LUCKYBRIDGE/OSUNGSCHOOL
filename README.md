# OSUNGSCHOOL

강릉오성학교 교사를 위한 **AI 활용·바이브코딩 연수** 자료 제작 저장소이다.

## 저장소 구성

```text
OSUNGSCHOOL/
├─ README.md
├─ AGENTS.md
├─ DESIGN.md
├─ docs/
│  ├─ 00_course_overview.md
│  ├─ 02_slide_outline.md
│  ├─ 03_speaker_script.md
│  └─ 04_sources.md
├─ slides/
│  ├─ source/
│  └─ pdf/
└─ references/
   └─ source/
```

## 핵심 제작 원칙

- 한 슬라이드에 하나의 핵심 메시지를 둔다.
- 강의 화면은 16:9로 제작한다.
- 슬라이드는 핵심 내용, 강의 대본은 상세 설명을 담당한다.
- 특수교육 교사의 도메인 지식을 사용자 흐름과 UX 설계로 연결한다.
- 도구 기능은 공식 문서를 우선해 확인한다.
- PDF는 생성 후 전 페이지 렌더링 검수한다.

## 현재 산출물

- `DESIGN.md`: 강의용 PDF/슬라이드 디자인 기준
- `docs/02_slide_outline.md`: 슬라이드별 화면 내용과 시각 구성
- `docs/03_speaker_script.md`: 슬라이드별 발표 대본
- `slides/pdf/osung_ai_vibecoding_lecture_v1.pdf`: 발표용 PDF
