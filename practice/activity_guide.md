# AI와 함께 수업·생활·업무 자료 만들기

해결해 보고 싶은 일을 떠올리고, 작은 결과부터 만들어 봅니다. 문장이나 메모, 간단한 그림으로 편하게 정리하세요. 예시와 다른 주제도 좋습니다.

## 생각이 막히면 참고하세요

- 어떤 일이 불편했나요? 누구에게 도움이 되면 좋을까요?
- 무엇을 만들어 보거나 바꿔 보고 싶나요?
- 써 본 뒤 어떤 점을 확인하고 싶나요?

질문마다 답을 쓸 필요는 없습니다. 떠오르는 내용부터 한 공간에 적고, 아직 정하지 못한 것은 ‘미정’으로 남겨도 됩니다. 기기나 사용 장소처럼 중요한 점이 생각나면 함께 메모하세요.

**내 아이디어와 메모**

(짧은 글·글머리표·그림 등 편한 방식으로 적습니다.)

예: “학생이 카페에서 음료를 고르고, 주문 전에 다시 확인할 수 있는 화면을 만들고 싶어요. 교실 태블릿에서 써 보고, 선택을 바꾸기 쉬운지 확인해 보고 싶습니다.”

교사가 쓸 수업 타이머, 읽기 쉬운 안전 안내문처럼 다른 주제로 바꿔도 됩니다.

## 쓸 수 있는 작업환경을 고릅니다

- 웹 채팅(ChatGPT·Gemini·Claude): 메모와 기준을 붙이거나 첨부하고, 결과 파일을 받아 직접 확인합니다.
- 전문 도구(Claude Code·Codex 등): 작업 폴더를 열고 기존 파일과 규칙을 먼저 읽게 합니다. 파일 제작·수정과 가능한 실행·검사를 요청하고, 실제 사용할 기기에서도 확인합니다.

두 환경에서 아래 흐름을 함께 씁니다. 규칙·개요는 기존 것이 있으면 이어서 고칩니다. 파일 이름과 시작 방법은 [공통 요청문과 환경별 안내](README.md)를 참고하세요.

## 필요한 만큼 정리하고 만들어 봅니다

진행이 막히면 **메모 → AI와 정리 → 작은 결과 만들기 → 직접 확인하고 수정**의 흐름을 참고하세요. 이미 생각한 내용이 있으면 그 부분부터 시작하고, 만들면서 계획을 바꿔도 됩니다.

아래 요청문은 고쳐 써도 됩니다. 괄호 안에 메모를 붙여 넣으세요.

```text
나는 교사이고, 아래 아이디어를 실제로 만들어 보고 싶어.
(내 메모)

메모를 바탕으로 무엇을 먼저 해 보면 좋을지 함께 정리해 줘.
진행에 꼭 필요한 정보가 빠졌다면 우선 중요한 것부터 짧게 질문해 줘.
내가 정하지 않은 내용은 임의로 확정하지 말고, 제안하거나 미정으로 남겨 줘.
개요와 설계 기준은 필요한 내용만 짧게 정리하고, 작은 부분부터 만들어 보자.
실제 학생 정보는 넣지 않고, 만든 결과를 어떻게 확인할지도 알려 줘.
```

예시의 화면 수·선택지 수·시간은 출발점입니다. 주제와 사용자에게 맞게 바꾸세요. 계획 문서를 처음부터 완성할 필요는 없고, 실제로 정한 내용에 맞춰 보완하면 됩니다.

## 해 본 결과를 남깁니다

만든 파일이나 화면을 열고, 의도한 행동이나 내용이 되는지 직접 확인하세요. 잘된 점과 고칠 점은 짧게 적어도 됩니다. 확인하지 못한 것은 ‘미확인’으로 남기세요.

예: “PC에서는 선택과 돌아가기를 확인했어요. 태블릿에서는 아직 열어 보지 못했습니다.”

형식은 자유롭게 쓰되 실제 학생 정보는 넣지 않고, 내용과 그림의 근거·사용 권한을 확인합니다. 과제로 제출할 때는 지정된 결과물과 개요·설계 기준 문서를 함께 남깁니다. 문서는 예시의 모든 항목을 채우기보다, 만든 결과를 이해하고 고쳐 쓰는 데 필요한 내용으로 정리하세요.

다음 작업을 위한 기준·인계·최신 결과물은 웹 채팅에 함께 첨부하거나, 전문 도구가 같은 작업 폴더에서 읽게 합니다. AI가 실행하지 못한 검사는 미확인으로 남깁니다.
