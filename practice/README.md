## 준비: 설치 없이 브라우저에서

1. ChatGPT·Claude는 '프로젝트', Gemini는 'Gem'을 만든다. 찾기 어려우면 새 대화로 해도 된다.
2. 아래 요청 1을 보낸다. AI의 질문에 답하면 규칙(AGENTS.md)과 개요(PROJECT_OVERVIEW.md) 초안이 나온다.
3. 초안을 읽고 고쳐서 지침 칸에 붙여 넣는다. 지침 칸이 없으면 대화 첫머리에 붙여 넣는다.

## 요청 1. 처음: 문서부터

요청 1은 어떤 주제든 쓸 수 있다. 요청 2~4는 학생용 웹 화면 예시이며 필요에 맞게 바꾼다. 자세한 운영 방법은 [활동 안내](activity_guide.md)를 참고한다. 질문에 모두 답한 뒤 시작할 필요는 없고, 개요와 규칙은 초안으로 정리해 만들면서 보완한다.

```text
나는 교사이고, 아래 아이디어를 실제로 만들어 보고 싶어.
(내 자유 메모)
진행에 꼭 필요한 정보가 빠졌다면 중요한 것부터 짧게 질문해 줘.
정하지 않은 내용은 제안하거나 미정으로 남겨 줘.
PROJECT_OVERVIEW.md와 AGENTS.md 초안부터 짧게 정리해 줘.
```

## 요청 2. 화면 기준(DESIGN.md)

```text
PROJECT_OVERVIEW.md를 바탕으로 DESIGN.md 초안을 만들어 줘.
- 대상: (예: 고등부 학생, 학교 태블릿 가로 화면)
- 학생용 터치 화면 예: 한 화면에 행동 하나, 버튼 높이 64px 이상, 본문 24px 이상
- 선택 상태·안내를 색만으로 구분하지 않는다
만든 뒤에는 내가 고칠 만한 부분 3가지를 알려 줘.
```

## 요청 3. 그림 시안 (선택)

```text
DESIGN.md를 참고해 '(화면 이름)' 화면 시안을 그림으로 그려 줘.
태블릿 가로 화면, (예: 음료 그림 2개), 큰 버튼, 위쪽에 '(1/4 단계)' 표시.
```

ChatGPT·Gemini에서 그림으로 받는다. 그림 속 한글은 틀릴 수 있으니 배치와 크기를 본다.

## 요청 4. 한 화면씩 만들기

```text
지금까지 정한 문서를 따라 1단계 '(화면 이름)' 화면만 만들어 줘.
- HTML 파일 하나로(모양과 동작 포함), 설치 없이 브라우저에서 열리게
- 완료 기준: (예: 음료를 누르면 테두리가 두꺼워지고 '다음' 버튼이 켜진다)
```

- 확인: ChatGPT는 코드 상자의 '미리보기', Gemini는 Canvas의 '미리보기', Claude는 옆에 열리는 창에서 눌러 본다. 보이지 않으면 아래 '만든 화면을 파일로 남기기'대로 저장해 연다.
- 폴더로 작업하는 도구(Codex·Claude Code·Antigravity)에서는 "AGENTS.md, PROJECT_OVERVIEW.md, DESIGN.md를 읽고"로 시작하고, "직접 열어서 확인하고, 확인한 방법을 알려 줘"를 덧붙인다.

## 요청 5. 이어서 하기

```text
AGENTS.md와 HANDOFF.md를 먼저 보고, '다음 할 일' 중 첫 번째만 진행해 줘.
완료 기준: (예: 3단계에서 '처음부터'를 누르면 1단계로 돌아간다)
끝나면 HANDOFF.md를 갱신해 줘.
```

## 막혔을 때

| 상황 | 이렇게 말한다 |
|---|---|
| 화면이 열리지 않는다 | "오류 메시지를 붙여 넣을게. 원인과 고치는 방법을 알려 줘" |
| AI가 너무 많이 바꿨다 | "방금 바꾼 것을 되돌리고, 요청한 부분만 다시 해 줘" |
| 대화가 길어져 헷갈린다 | "지금까지를 HANDOFF.md로 정리해 줘" → 새 대화에 붙여 넣고 요청 5 |
| 같은 실패가 세 번째다 | 멈추고 요청을 더 작게 나눈다 |

## 다 만든 뒤 5분 확인

- [ ] 학생처럼 처음부터 끝까지 해 본다
- [ ] 일부러 틀리게 눌러 본다
- [ ] 새로고침과 뒤로 가기를 눌러 본다
- [ ] 실제 태블릿에서 연다
- [ ] 글을 읽지 않고 그림만으로 할 수 있는지 본다

## 만든 화면을 파일로 남기기

1. 코드 상자의 복사 버튼으로 코드를 복사한다.
2. 윈도우 메모장에 붙여 넣고 '다른 이름으로 저장'을 누른다.
3. 파일 이름 `index.html`, 파일 형식 '모든 파일', 인코딩 'UTF-8'로 저장한다.
4. 파일을 두 번 누르면 브라우저에서 열린다. 공개하려면 index.html을 저장소 맨 위에 올리고, Pages에서 main 브랜치와 /(root)를 지정한다. 배포가 끝난 뒤 실제 주소를 열어 확인한다.

## 학교에서 지킬 것

- 이름·사진·진단명 대신 '학생 A'와 수행 특성만 쓴다.
- AI는 교사가 쓰고, 학생은 완성된 화면만 쓴다.
- 무료 공개 주소(GitHub Pages)는 누구나 본다. 학생 기록은 두지 않는다.
- 그림은 직접 만들었거나 사용 허락이 분명한 것만 쓴다.
- 학교 계정 연결과 권한은 꼭 필요한 것만 허용한다.
- 안내 문구·가격·사실은 교사가 확인한다.
- 학교·교육청의 AI 활용 지침이 있으면 그것을 먼저 따른다.

## 양식: 규칙 (AGENTS.md)

학생용 터치 웹 화면을 만드는 예시다. 요청 1 없이 시작하고 싶을 때 지침 칸에 넣고, 다른 결과물은 대상·표현·확인 방법에 맞게 바꾼다.

```markdown
# 규칙 (AGENTS.md)
- 나는 특수학교 교사이고, 학생이 쓸 연습 자료를 만든다
- 학생 이름·사진·진단명 등 개인정보를 넣지 않는다
- 한 화면에는 행동을 하나만 둔다
- 버튼 높이 64px 이상, 본문 글자 24px 이상
- 요청하지 않은 기능을 더하지 않는다
- 진행에 꼭 필요한 정보만 먼저 묻고, 미정은 만들면서 보완한다
- 고친 뒤에는 무엇이 바뀌었고 어떻게 확인하면 되는지 알려 준다
```

## 양식: 인계 (HANDOFF.md)

막힐 때 참고하는 항목이다. 한 공간에 짧게 메모해도 되고, 해당하지 않는 항목은 비워 둬도 된다.

```markdown
# HANDOFF.md
## 지금 상태
- 
## 정한 것과 이유
- 
## 안 된 방법
- 
## 다음 할 일
1. 
```
