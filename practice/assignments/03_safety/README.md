# 과제 3 · 행동이 보이는 안전교육 자료 만들기

과제 1 뒤에 선택하는 제작 과제입니다. 학생의 생활 장면 하나에 맞춘 포스터 또는 인포그래픽 한 장을 만듭니다.

예시는 **복도에서 안전하게 이동하기**입니다. 횡단보도·화재·물놀이 등으로 바꾸면 해당 공식 행동요령과 학교의 절차를 먼저 확인하고 문서에 근거를 적습니다.

1. `overview.md`에서 대상·장면·행동·근거를 정합니다.
2. `design.md`에서 지면과 읽는 순서를 정합니다.
3. `prompt.md`로 문구를 먼저 검토한 뒤 자료를 만듭니다.
4. 최종 PNG·PDF와 두 문서, 편집 원본 또는 Figma 링크를 제출합니다.

완성 이미지만 그럴듯하면 충분한 것이 아닙니다. **한글·그림의 행동·읽는 순서·실제 출력·안전 정보의 근거**를 교사가 확인합니다.
이미지 AI의 한글이 틀리면 편집 가능한 텍스트로 다시 넣습니다. AI가 확인하지 못한 행동요령은 미확인으로 남깁니다.
