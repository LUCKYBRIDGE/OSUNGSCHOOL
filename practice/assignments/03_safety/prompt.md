# 과제 3 복사용 요청문

## 1. 안전 문구와 근거부터

```text
overview.md와 design.md를 읽고 학생용 안전교육 포스터 한 장을 만들고 싶어.
주제와 가상 학생의 수행 조건: ( )
학교에서 확인한 지도 기준과 공식 자료 내용: (자료 제목·링크·확인한 본문)
먼저 학생이 할 행동 3개와 도움 요청 문장을 짧게 제안해줘.
각 문구가 어느 근거에 기반하는지 표시하고, 확인하지 못한 행동요령은 만들지 마.
내가 문구를 확인하기 전에는 최종 이미지나 포스터를 만들지 마.
문구가 대상의 이동·시각·언어 수행 조건과 맞는지 설명하고 두 문서를 갱신해줘.
```

## 2. 한 장 제작

```text
확정한 문구와 design.md를 따라 A4 세로 안전교육 포스터 한 장을 만들어줘.
위는 제목, 가운데는 번호·행동 그림·짧은 문장 3개, 아래는 도움 요청과 출처야.
제목 28pt 이상, 행동 문구 20pt 이상, 도움 요청 18pt 이상을 지켜줘.
색만으로 구분하지 말고 번호·그림·문장을 함께 써줘.
한글은 편집 가능한 텍스트로 넣고, 그림이 글의 행동을 정확히 보여주는지 확인해줘.
최종 PNG·PDF와 편집 원본을 남겨줘. 해당 형식을 만들 수 없으면 가능한 형식과 변환 방법을 알려줘.
이미지 AI로 그림을 만들었다면 그 안의 잘못된 한글을 그대로 최종본에 쓰지 마.
```

## 3. 검토와 제출

```text
최종 자료를 실제로 열어 한글 오탈자·잘림·겹침·행동 순서·그림과 문구의 일치를 확인해줘.
근거를 읽은 사실, 문구를 검토한 사실, 출력 미리보기, 실제 인쇄 확인을 구분해줘.
직접 확인하지 못한 항목은 미확인으로 적고 교사가 확인할 방법을 알려줘.
다른 선생님이 수정할 원본과 문서가 어디 있는지, 참고·그림 출처도 정리해줘.
```
