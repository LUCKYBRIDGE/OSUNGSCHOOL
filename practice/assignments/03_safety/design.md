# design.md · 안전교육 포스터 지면 기준

## 지면과 읽는 순서
- A4 세로 210×297mm, 상하좌우 여백 12mm 이상.
- 위: 제목 / 가운데: 번호+행동 그림+짧은 문장 3개 / 아래: 도움 요청+작은 출처.
- 순서는 위에서 아래로 흐른다. 그림을 보고 어디부터 읽는지 찾을 수 있게 한다.
- 학생에게 보여 줄 행동 문장은 짧게, 교사용 근거와 설명은 개요 문서로 옮긴다.

## 글자·색·그림
- A4 예시: 제목 28pt 이상, 행동 문구 20pt 이상, 도움 요청 18pt 이상, 교사용 출처 9pt 이상.
- 글자가 넘치면 문구를 줄이거나 그림 배치를 바꾼다. 최소 크기 아래로 축소하지 않는다.
- 배경 #FFFFFF, 본문 #1F2933, 강조 #1D5FD1. 흑백에서도 번호·그림·문구로 구분된다.
- 그림은 한 장면에 한 행동을 나타낸다. 안전한 행동이 실제 문구와 일치하는지 확인한다.
- 학생 사진·기관 로고·캐릭터는 임의로 가져오지 않는다. 직접 제작 또는 사용 허락이 확인된 그림을 쓴다.
- 겁주는 표현, 복잡한 배경, 작은 장식 글자, 색만으로 구분하는 금지 표시는 피한다.

## 제작과 확인
- 한글 문구는 편집 가능한 텍스트로 둔다. 이미지 AI가 만든 글자는 정확히 다시 입력하고 확인한다.
- PNG는 A4 비율로 내보내고, 인쇄용 PDF는 A4로 저장한다. 최종 PNG·PDF와 원본을 직접 열어 확인한다.
- 학교 안전 담당자의 확인이 필요한 문구는 확인 전 확정하지 않는다.
- 실제 출력 전에는 미리보기 확인으로 기록한다. 출력하지 않았는데 인쇄 확인 완료라고 쓰지 않는다.
