# 과제 1 · 좋은 아이디어를 설명하기

모든 선생님이 먼저 진행합니다. 코드를 만들기 전에 **누구에게 무엇이 왜 필요한지**를 정합니다.

1. `overview.md`의 예시를 자신의 문제로 바꿉니다.
2. `design.md`에 계획한 결과물의 기준과 이유를 적습니다.
3. `prompt.md`를 복사해 질문과 피드백을 받습니다.
4. `idea.md`에 아이디어를 짧게 정리합니다.
5. 과제 2·3·4 중 하나를 골라 제작하고, 공통 제출 양식을 함께 채웁니다.

완료 기준: 대상·불편·기존 방법·작은 해결책·효과를 관찰할 방법을 설명할 수 있습니다.
앱·그림·자동화가 필요 없는 아이디어도 가능합니다. 과제 1 단계에서는 결과물 제작을 요구하지 않습니다.

예시 주제는 카페 주문 연습입니다. 다른 주제로 바꾸면 두 문서의 대상·범위·기준도 함께 고치세요.
