# 과제 1 복사용 요청문

두 문서를 첨부하거나, 이름을 표시해 내용을 붙여 넣은 뒤 보냅니다.

```text
나는 특수학교 교사야. overview.md와 design.md 예시를 내 아이디어에 맞게 고치고 싶어.
내 아이디어: (누가 / 어떤 상황에서 / 어떤 불편을 / 무엇으로 해결할지)
가상 학생의 수행 조건과 사용 환경: ( )
바로 만들지 말고 빠진 조건을 중요한 질문 3개 이내로 물어봐줘.
내 답을 반영해 overview.md에 대상·문제·기존 방법·목표·이번 범위·완료 기준을 정리해줘.
design.md에는 결과물의 흐름·문구·시각 단서·실수 복구 기준과 교육적 이유를 적어줘.
아이디어를 idea.md 양식의 짧은 글로 정리하고, 과제 2·3·4 중 연결할 수 있는 방향을 제안해줘.
학생을 무조건 기능을 줄여야 하는 대상으로 보지 말고, 실제 학생 개인정보는 가상 사례로 바꿔줘.
지금은 아이디어·문서 단계야. 웹이나 포스터를 완성했다고 쓰지 마.
파일 생성이 안 되면 각 파일 이름과 복사할 내용을 따로 보여줘.
```

```text
이 아이디어를 검토해줘. 대상·문제·해결책·완료 기준이 이어지는지 보고,
좋은 점 하나와 가장 먼저 고칠 점 하나를 이유와 함께 알려줘.
내가 선택한 과제 (2/3/4)에 맞게 overview.md와 design.md를 갱신해줘.
```
