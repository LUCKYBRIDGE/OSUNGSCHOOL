# overview.md · 아이디어 예시: 주문 전에 한 번 연습하기

## 문제와 대상
- 가상 학생 A는 그림과 짧은 문장으로 선택하고, 주문 직전에 선택을 다시 확인할 기회가 필요하다.
- 실제 카페에서는 다음 순서를 모르면 주문을 망설이거나 잘못 선택한 뒤 되돌아가기 어렵다.
- 기존 방법: 메뉴 사진·역할놀이로 연습한다. 선택부터 확인까지 이어지는 반복 연습을 보완하고 싶다.

## 목표
- 학생이 음료를 선택하고, 주문 내용을 확인하고, 실수하면 돌아가서 수정하는 행동을 연습한다.
- 성공은 ‘예쁜 화면’이 아니라 학생이 선택·확인·수정을 이해하는지로 판단한다.

## 사용 조건
- 교실 태블릿 또는 PC, 교사와 함께 연습, 실제 학생 정보와 실제 결제 없음.
- 그림+짧은 문장으로 안내한다. 필요한 도움 방식은 교사가 조정한다.

## 이번 범위
- 메뉴 선택 → 수량 선택 → 내용 확인 → 연습 완료의 네 단계.
- 메뉴 3개와 수량 1~3개는 예시다. 학생의 수행 조건에 따라 이유를 적고 바꾼다.
- 로그인·결제·주문 전송·개인별 기록·관리자 화면은 이번 범위에 넣지 않는다.

## 교육적 이유
- 선택지를 줄이는 것 자체가 목표는 아니다. 먼저 익힐 선택과 실수 복구 행동에 집중한다.
- 익숙해지면 메뉴·선택 조건을 늘려 실제 카페 연습과 연결한다.

## 완료 기준과 관찰
- 아이디어 글에서 대상·문제·기존 방법·작은 해결책·확인 방법을 각각 설명한다.
- 문서의 목표와 계획한 네 단계가 맞는다.
- 제작 후 관찰할 것: 선택 표시를 알아보는가, 확인 화면에서 내용을 설명하는가, 바꾸기 기능을 찾는가.
- 실제 학생 관찰은 이 문서에서 수행했다고 쓰지 않는다. 교사의 모의 확인과 향후 관찰을 구분한다.
