# 결과물 제출

아래 양식을 복사해 Padlet **「08 · 결과물 제출」의 새 게시글**에 붙여 넣습니다.
괄호를 채우고 ZIP이나 링크를 추가하세요.

```text
제목: [과제2/3/4] (결과물 이름) · (제출자 이름)

아이디어: (누구의 어떤 불편을 해결하려 했나요? 2~3문장)
결과물: (ZIP / 만든 사이트 / GitHub 저장소 / Figma 링크)
개요 문서: (overview.md 또는 prd.md 위치)
설계 문서: (design.md 위치)
열어 보는 방법: (처음 열 파일 또는 확인할 화면)
직접 확인한 것: (기기, 버튼 동작, 출력 상태 등)
남은 문제: (없으면 ‘없음’, 확인하지 못한 것은 ‘미확인’)
Figma MCP: (사용했다면 읽은 화면과 반영한 점, 사용하지 않았다면 ‘미사용’)
의견을 받고 싶은 점: (한 가지)
참고·그림 출처: (사용했다면 링크)
```

아이디어만 먼저 올릴 때는 제목을 `[과제1] (아이디어 이름)`으로 쓰고, 결과물 칸에 아이디어 글을 넣습니다. 선택 과제를 완성하면 같은 글에 추가해도 됩니다.

## 올리기 전 확인

- [ ] 결과물과 두 문서를 함께 볼 수 있습니다.
- [ ] ZIP을 풀어 파일을 열거나, 다른 사람이 볼 수 있는 권한으로 링크를 확인했습니다.
- [ ] 확인한 것과 아직 확인하지 못한 것을 구분했습니다.
- [ ] 실제 학생 정보나 비밀 키가 들어 있지 않습니다.
