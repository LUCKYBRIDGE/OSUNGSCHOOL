# Padlet 제출 양식

아래 본문을 복사해 ‘08 · 결과물 제출’의 **새 게시글**에 작성합니다.
괄호를 채우고, 사용하지 않는 제출 방식은 지웁니다. 과제 1과 선택 과제를 함께 제출할 수 있습니다.

```text
제목: [과제2/3/4] (결과물 이름) · (제출용 이름)

1. 선택 과제: (2 키오스크 / 3 안전교육 / 4 자유 결과물)
2. 과제 1 아이디어: (누구의 어떤 불편을 무엇으로 해결하려는지 2~3문장)
3. 대상·사용 장면: (가상 학생의 수행 조건 / 기기·지면 / 수업 장면)
4. 결과물: (ZIP 첨부 / 만든 사이트 / GitHub 저장소 / Figma 프레임 링크)
5. 공통 문서: (overview.md 또는 prd.md 위치 / design.md 위치)
6. 열어 보는 방법: (압축을 풀어 열 파일 / 링크의 확인할 화면·프레임 / 필요한 실행 명령)
7. 직접 확인한 것: (어떤 기기·크기에서 어떤 행동·출력·근거를 확인했는지)
8. 미확인·남은 문제: (없으면 없음, 확인하지 않은 내용은 미확인)
9. Figma MCP: (사용 / 미사용)
   사용했다면: (읽은 프레임 / 반영한 요소 / 비교해서 고친 점)
   미사용했다면: (이유와 대신 확인한 방법)
10. 도움받고 싶은 점: (한 가지)
11. 참고·그림 출처: (출처 링크 또는 직접 제작·사용 허락)
```

아이디어를 먼저 공유할 때는 제목을 `[과제1] (아이디어 이름) · (제출용 이름)`으로 쓰고,
1번을 ‘과제 1’, 4번을 아이디어 글의 파일·본문, 6·7번을 아이디어와 문서 검토 방법으로 바꿉니다.
선택 과제까지 완성하면 같은 글을 갱신하거나 관련 글 링크를 서로 붙입니다.

## 제출 전 확인

- [ ] 과제 1의 아이디어와 선택 과제 결과가 함께 확인된다.
- [ ] `overview.md` 또는 `prd.md` 하나와 `design.md`를 첨부하거나 링크했다.
- [ ] ZIP을 새 폴더에 풀어 결과 파일을 열거나, 제출 링크를 확인자 권한으로 열어 봤다.
- [ ] 실제로 확인한 결과와 미확인 내용을 구분했다.
- [ ] 학생 개인정보·비밀 키·로그인 정보·불필요한 설치 폴더가 없다.
- [ ] 자료의 문구·그림·가격·안전 정보와 사용 권한을 확인했다.
