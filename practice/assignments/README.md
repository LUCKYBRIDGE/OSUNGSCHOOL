| 과제 | 할 일 | 제출할 결과 |
|---|---|---|
| [1 · 자유 아이디어](01_idea/README.md) | 누구의 어떤 불편을 해결할지 적기 | 아이디어 글 |
| [2 · 생활 키오스크](02_kiosk/README.md) | 카페 주문 등 생활 장면을 연습하는 웹 만들기 | 작동하는 웹 파일 또는 사이트·저장소 링크 |

| [4 · 자유 결과물](04_free/README.md) | 수업·생활·업무에 필요한 자료 만들기 | 열어 볼 수 있는 파일 또는 링크 |

## 시작하기

1. 아래 ZIP을 내려받아 압축을 풉니다.
2. 과제 1 폴더의 예시를 자신의 아이디어로 고칩니다.
3. 선택한 과제 폴더에서 `overview.md`와 `design.md`를 고칩니다.
4. `prompt.md`의 요청문을 AI에 보냅니다. 두 문서를 첨부하거나 내용을 붙여 넣습니다.
5. 결과를 직접 확인한 뒤 [제출 양식](submission.md)을 채웁니다.

예시의 주제, 선택지 수, 글자 크기는 학생과 수업 상황에 맞게 바꿔도 됩니다.

## 함께 준비할 문서

- **`overview.md` 또는 `prd.md` 하나**: 누구를 위한 자료인지, 무엇을 만들지, 어디까지 완성할지 적습니다.
- **`design.md`**: 화면·지면의 구성, 글자, 버튼, 안내 문구를 어떻게 정했는지 적습니다.

기존 `PROJECT_OVERVIEW.md`와 `DESIGN.md`가 있다면 내용을 옮겨 활용해도 됩니다. 같은 문서를 두 번 작성할 필요는 없습니다.

Figma MCP는 가능하면 활용해 보세요. 설계를 AI에 읽힌 뒤 결과와 비교하는 데 쓸 수 있습니다. 연결이 어려우면 설계 문서와 화면 캡처로 진행해도 됩니다.

## 제출 방법

**Padlet 「08 · 결과물 제출」에 새 게시글로 올립니다.** 과제 1과 선택 과제를 한 글에 담아도 됩니다.

- Figma 링크: 확인할 화면을 지정하고 두 문서도 함께 올립니다. 과제 2는 실제로 작동하는 웹이 필요합니다.
