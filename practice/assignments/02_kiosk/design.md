# design.md · 카페 주문 연습 웹 기준

## 화면 구조
- 한 화면에 중심 행동 하나. 상단에 ‘주문 연습 · 1/4’처럼 현재 단계를 표시한다.
- 중앙은 선택 또는 확인, 하단은 도움·돌아가기·다음의 위치를 일관되게 둔다.
- 그림에는 이름을 함께 표시하고, 사용하지 않은 실제 회사 로고나 결제창을 흉내 내지 않는다.

## 글자·버튼·색
- 제목 32px 이상, 본문 24px 이상, 버튼 높이 64px 이상, 버튼 사이 간격 16px 이상.
- 배경 #FFFFFF, 본문 #1F2933, 주 버튼 #1D5FD1, 보조 영역 #F3F5F8를 예시로 사용한다.
- 선택은 두꺼운 테두리+체크 표시+‘선택됨’ 문구. 색만으로 전달하지 않는다.
- 핵심 그림은 직접 만든 SVG 등 파일 안에 포함한다. 글꼴은 기기의 한글 기본 글꼴을 사용한다.

## 이해·오류 복구
- 문구 예: ‘마실 것을 골라요’, ‘몇 개를 고를까요?’, ‘주문 내용을 확인해요’.
- 미선택이면 ‘음료를 먼저 골라요’처럼 바로 할 행동을 알려준다.
- 바꾸기에서 선택을 유지하고, 다시 연습하기에서 초기화한다.
- 수량은 정한 범위에서만 바뀌고 빠르게 여러 번 눌러도 범위를 벗어나지 않는다.
- 경고음·깜빡임·배경음·시간 제한·자동 이동은 기본으로 넣지 않는다.

## 기기와 직접 확인
- 목표 크기: PC 1280×720, 태블릿 1024×768. 휴대폰 390×844에서도 핵심 행동이 가능하게 조정한다.
- 공간이 모자라면 열 수·배치를 바꾼다. 글자 크기를 줄여 끼워 넣지 않는다.
- Tab 이동·Enter/Space 실행과 보이는 포커스 표시를 확인한다.
- 화면·흐름·계산·돌아가기·초기화를 실제로 확인하고 결과를 남긴다.
