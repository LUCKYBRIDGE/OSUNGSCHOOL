# 과제 2 복사용 요청문

## 1. 문서부터 확인

```text
overview.md와 design.md를 읽고 카페 주문 연습 키오스크 웹을 만들고 싶어.
내가 바꾼 주제·사용 조건: ( )
두 문서의 목표·화면 흐름·계산·실수 복구·완료 기준이 맞는지 먼저 확인해줘.
필요한 질문은 3개 이내로 하고, 문서 수정 후 내가 확인할 핵심 기준을 정리해줘.
실제 결제·로그인·주문 전송·학생 기록 없이, PC에서 파일로 열 수 있는 index.html 하나로 만들어줘.
외부 라이브러리·그림·글꼴 호출 없이 동작하게 해줘. 아직 전체를 한꺼번에 만들지 마.
```

## 2. 한 화면씩 만들기

```text
두 문서를 따라 첫 메뉴 선택 화면만 만들어줘.
메뉴 3개는 그림·이름·가상 가격을 보여주고, 선택을 색+테두리+문구로 표시해줘.
선택하지 않고 다음을 누르면 해야 할 행동을 알려줘.
버튼 높이 64px 이상, 본문 24px 이상을 지키고 키보드 포커스를 표시해줘.
첫 화면을 열어 확인할 방법과 아직 연결하지 않은 다음 단계를 알려줘.
내가 확인한 뒤 수량 → 주문 확인 → 완료 화면을 하나씩 연결하자.
```

## 3. 전체 동작 확인과 제출 준비

```text
overview.md의 완료 기준으로 전체 흐름을 확인해줘.
물 2개=2,000원, 우유 3개=4,500원, 주스 1개=2,000원인지 확인해줘.
미선택, 수량 범위, 바꾸기에서 선택 유지, 다시 연습에서 초기화도 확인해줘.
가능하면 PC 1280×720, 태블릿 1024×768, 휴대폰 390×844와 키보드 조작을 확인해줘.
직접 실행하지 못한 항목은 미확인으로 적고 내가 따라 할 확인 방법을 알려줘.
최종 결과와 두 문서를 맞추고, 다른 선생님이 열 파일·실행 방법·남은 문제를 정리해줘.
```

Figma MCP를 활용할 수 있다면 공통 안내의 선택 심화 요청문을 문서 확정 후에 사용합니다.
