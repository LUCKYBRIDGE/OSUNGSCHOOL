# 과제 2 · 일상생활 키오스크 웹 만들기

과제 1 뒤에 선택하는 제작 과제입니다. 카페·음식점·도서관 대출·무인 발권 등 학생이 경험할 장면 하나를 고릅니다.

예시는 **실제 결제가 없는 카페 주문 연습**입니다. 주제를 바꾸면 두 문서의 절차와 완료 기준도 고칩니다.

1. `overview.md`와 `design.md`를 자신의 아이디어로 수정합니다.
2. `prompt.md`의 시작 요청 → 한 화면 제작 → 전체 확인 순서로 보냅니다.
3. 한 화면씩 확인해 3~5단계의 작은 웹을 만듭니다.
4. 결과 HTML·필요 파일 또는 작동하는 사이트·저장소 링크와 두 문서를 제출합니다.

**Figma 화면 시안만 제출하면 웹의 동작은 확인할 수 없습니다.** Figma를 사용했다면 웹 결과와 함께 연결합니다.
직접 실행한 기기·화면 크기·버튼 동작·남은 문제를 제출 양식에 적습니다. 확인할 수 없는 환경은 미확인으로 남깁니다.
