# overview.md · 카페 주문 연습 키오스크

## 대상과 문제
- 가상 학생 A는 그림+짧은 문장으로 선택하며, 주문 전에 선택 내용을 확인하고 수정하는 연습이 필요하다.
- 실생활 카페 주문을 역할놀이와 연결한다. 연습 화면만으로 실제 생활 수행이 검증되었다고 보지 않는다.

## 목표와 사용 조건
- 음료·수량 선택 → 주문 내용 확인 → 바꾸기 또는 연습 완료를 스스로 시도한다.
- PC·태블릿 브라우저, 교사가 준비한 연습 화면, 실제 결제·로그인·학생 정보·주문 전송 없음.
- 기본 결과는 외부 라이브러리·그림·글꼴 호출 없이 열리는 `index.html` 한 파일로 만든다.
- 파일형 PC 실행과 사이트 주소 실행은 각각 확인한다. 태블릿에서 로컬 파일을 여는 방식은 기기별로 확인한다.

## 이번 범위
1. 메뉴 고르기: 물 1,000원 / 우유 1,500원 / 주스 2,000원 중 하나.
2. 수량 고르기: 1~3개.
3. 확인하기: 메뉴·수량·합계 표시, ‘바꾸기’와 ‘주문 연습 완료’.
4. 완료: 연습 완료 문구와 ‘다시 연습’.

가격은 **가상 연습 값**이며 실제 판매 가격이 아니다. 메뉴·가격·수량 범위를 고치면 화면과 계산도 함께 수정한다.
로그인·결제 API·주문 기록·관리자·자동 시간 제한은 넣지 않는다.

## 완료 기준
- 선택 전 다음 단계로 진행하지 않고 무엇을 골라야 하는지 안내한다.
- 선택 표시와 확인 화면의 메뉴·수량·합계가 일치한다.
- 물 2개는 2,000원, 우유 3개는 4,500원, 주스 1개는 2,000원으로 표시한다.
- ‘바꾸기’에서 이전 선택을 유지한다. ‘다시 연습’에서 선택·합계·단계를 초기화한다.
- 실제 결제가 일어났다고 보일 수 있는 안내나 버튼을 사용하지 않는다.
- PC와 태블릿 크기에서 잘림·겹침·가려진 버튼이 없고 키보드로 주요 버튼을 사용할 수 있다.
