# 과제 4 · 자유 결과물 만들기

과제 1 뒤에 선택하는 제작 과제입니다. 수업·생활·업무의 실제 문제를 해결할 결과물 하나를 만듭니다.

예: 순서 카드, 역할놀이 활동지, 쉬운 안내문, 생활 연습 웹, 수업 준비 보조 도구.
학생이 직접 쓰는 결과물과 교사가 쓰는 결과물의 대상을 구분합니다.

1. 과제 1의 아이디어를 `overview.md`에 옮기고 이번에 만들 범위를 줄입니다.
2. 결과물의 매체에 맞게 `design.md`를 채웁니다.
3. `prompt.md`로 작은 결과 하나를 만든 뒤 확인하고 고칩니다.
4. 실제 결과 파일 또는 사이트·저장소·Figma 링크와 두 문서를 제출합니다.

완료 기준은 직접 확인할 수 있는 행동·출력으로 적습니다. Figma 링크를 제출할 때는 해당 설계가 최종 결과인지, 작동하는 결과의 시안인지 구분합니다.
