# 과제 4 복사용 요청문

```text
overview.md와 design.md를 읽고 (결과물 형식)을 만들고 싶어.
과제 1에서 정한 아이디어와 가상 대상의 수행 조건을 유지해줘.
매체에 맞는 완료 기준과 설계 기준이 빠져 있으면 질문 3개 이내로 확인해줘.
문서를 고친 뒤 핵심 결과 하나부터 만들어줘. 요청하지 않은 기능은 추가하지 마.
학생이 쓰는 자료인지 교사가 쓰는 도구인지 구분하고, 개인정보는 넣지 마.
문서의 기준으로 직접 열거나 실행해 확인하고, 확인하지 못한 것은 미확인으로 적어줘.
최종 결과와 두 문서를 맞추고 다른 선생님이 열고 수정할 파일·링크·방법을 정리해줘.
파일 생성이 안 되면 이름과 복사할 내용을 따로 보여줘.
```

Figma MCP가 연결되면 공통 안내의 선택 심화 요청문을 사용해 설계와 결과를 비교합니다.
