## 강의에서 사용하는 주요 확인 내용

1. OpenAI Plugin은 Skill과 connected App 등을 묶는 워크플로 패키지가 될 수 있다.
2. Claude는 외부 앱·서비스 연결에 Connector라는 용어를 사용한다.
3. Figma 공식 MCP 문서는 Claude Code와 Codex 연결을 안내한다.
4. Stitch는 DESIGN.md 규격을 공개했고 Google Antigravity로 화면을 export하는 흐름을 제공한다.
5. Anthropic 해커톤 공식 사례에는 의사 출신 SW 엔지니어, 전자수리 현장 경험자, 컴퓨터과학 교수 등 다양한 배경의 우승자가 등장한다.
