# 2026 찾아가는 학교 컨설팅 강의자료 분할 운영안

- 강의명: 4. AI·디지털 문제해결 실무 과정
- 일시: 2026. 9. 30.
- 대상: 강릉오성학교 교사
- 주강사: 서정완
- 운영 방식: 1부와 2부를 분리된 PPT/PDF로 운영한다.

## 분할 원칙

기존 마스터 자료는 전체 흐름 보존용으로 두고, 실제 발표는 두 파일로 나눈다.

1. **1부: 문제 정의와 AI 작업환경**
   - 문제 찾기, 사용 조건 판단, 최소 개발 지식, 하네스, ECC, 작업공간, Handoff를 다룬다.
   - 핵심 메시지: 교사는 문제와 조건을 판단하고, AI가 반복해서 잘 일할 수 있는 작업환경을 만든다.

2. **2부: UX/UI 설계와 구현·검증 실습**
   - UX/UI, DESIGN.md, 디자인 도구, 구현·검증·배포, 오성학교 실습을 다룬다.
   - 핵심 메시지: 기능 구현에서 끝내지 않고 실제 사용자가 쓸 수 있는 도구로 완성한다.

## 설명 순서

1부에서는 작은 불편에서 시작해 개발 최소 지식을 정리한 뒤, AI가 장기 작업을 이어갈 수 있도록 하네스와 작업공간 개념으로 연결한다.
2부에서는 기능 구현 이후의 사용성 문제를 출발점으로 삼아 화면 설계, 디자인 도구, 검증, 배포, 실습 산출물로 이어간다.
