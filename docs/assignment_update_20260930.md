## 문구 검토

- 참가자가 읽는 본문은 할 일, 짧은 순서, 직접 확인할 내용으로 정리했다.
- 강사 발언과 진행 메모, 우열을 설득하는 장문, 설치 설정의 나열을 본문에서 줄였다.
- 앱별 설치는 현재 공식 설치 방법을 AI에 확인·적용하게 하는 복사 요청문으로 제공한다. 일반 채팅과 프로젝트를 다루는 앱을 구분한다.
- 공식 자료는 작성 근거로 유지한다. 개발 문서 읽기를 실습의 선행 조건으로 두지 않는다.
- 복사 프롬프트와 예시 문서의 상세 조건은 유지한다. 실제 설치나 실제 웹·포스터 제작 완료로 기록하지 않는다.
- 주요 사실의 근거는 [기존 사실 검토 기록](padlet_update_20260930.md)을 참조한다.
