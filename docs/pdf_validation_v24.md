## 출력 검증

- Windows Chrome + Playwright 인쇄 렌더링: 1부 `QA slides=42 / OK`, 2부 `QA slides=35 / OK`, 활동지 `QA pages=2 / OK`.
- 기존 자동 검사 기준으로 쪽·상자 넘침, 작은 글자, 안전영역 이탈, 의도하지 않은 상자 겹침 0건. 활동지 본문 9pt·바닥글 8pt 이상을 유지했다. 글자를 줄여 공간을 맞추지 않았다.
- pypdf로 PDF 전 쪽이 열리고 텍스트가 존재하는지 확인했다. 슬라이드 전 쪽의 16:9와 한글 대체 문자 0건을 확인했다. Chrome의 A4 출력은 594.96×841.92pt, 대본은 595.28×841.89pt다.
- PDF 전체 100쪽을 pypdfium2로 렌더링하여 전 페이지를 확인했다. 바뀐 활동지 뒷면과 주요 페이지는 확대하고, 대본의 변경 이후 페이지 흐름을 재확인했다. 글자 잘림·한글 깨짐·겹침 0건.
- 사용된 PDF 글꼴 리소스는 모두 포함되어 있다: 1부 6종, 2부 6종, 활동지 5종, 대본 5종(부분 포함 글꼴 이름 기준).
- ZIP 내부 CRC와 원본 파일의 바이트 일치를 검사했다. 묶음의 `읽어주세요.txt`에 파일별 SHA-256을 제공한다. 현재 README·실습 안내의 로컬 다운로드 링크와 보존용 배포 사본의 해시도 확인했다.
