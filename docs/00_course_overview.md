# 강릉오성학교 AI 활용·바이브코딩 연수 개요

## 대상

강릉오성학교 교사이다. 특수교육 현장의 실제 필요를 중심으로 AI를 수업·업무·교육자료 제작·바이브코딩에 활용하는 방법을 다룬다.

## 핵심 메시지

1. 좋은 프롬프트 한 번보다 AI가 지속적으로 잘 일할 작업환경이 중요하다.
2. 바이브코딩에서 교사의 도메인 지식은 구현 능력만큼 중요하다.
3. 그럴싸한 UI보다 사용자가 헤매지 않는 UX가 중요하다.
4. 설계 문서와 시각 도안을 먼저 만들면 구현 시행착오를 줄일 수 있다.
5. 구현·검토·실행 검증·배포·피드백을 하나의 반복 흐름으로 본다.

## 강의 큰 흐름

- Harness / Loop / Graph
- Rules, Docs, Skills, Agents, Hooks, MCP
- 프로젝트 폴더와 상하위 지침
- 좋은 서비스와 특수교육 UX
- DESIGN.md와 시각적 설계
- ChatGPT/Gemini, Stitch, Claude Design, Figma
- 구현·검토·검증·배포
- 컨텍스트·토큰 최적화
- 오성학교 생활 밀착형 웹자료 실습
