# 강릉오성학교 AI·디지털 문제해결 실무 과정 개요 (v21)

## 대상

강릉오성학교 교사(전문 개발자가 아닌 특수교육 교사). 생활·수업·업무의 작은 불편을 AI와 디지털 도구로 직접 해결해 보는 실무형 연수다.

## 핵심 메시지

1. 만들 것은 앱이 아니라 해결할 문제다. 문제 한 문장과 사용 조건부터 정한다.
2. 좋은 질문 한 번보다 AI가 같은 기준으로 계속 일할 작업환경(규칙·문서·스킬·인계 파일)이 중요하다.
3. 교사의 도메인 지식(학생 이해)은 구현 능력만큼 중요한 입력이다.
4. 그럴싸한 화면보다 학생이 헤매지 않는 흐름이 먼저다.
5. 작게 만들고, 완료 기준으로 직접 확인하고, 공개한 뒤 관찰해 다시 고친다.

## 강의 큰 흐름

### 1부. 문제 정의와 AI 작업환경 (44쪽)

- 작은 불편에서 시작하기: 문제 한 문장, 사용 조건
- AI와 말이 통하는 최소 지식: 웹앱/설치형, 화면·처리·기록, API/MCP, GitHub/배포
- 질문 한 번에서 작업환경으로: 하네스, ECC 공개 사례, 해커톤 수상자
- 작업환경을 이루는 것들: 규칙 파일, 프로젝트 문서, 스킬, 에이전트, 도구 연결, 완료 기준
- 작업공간과 인계: 프로젝트 폴더, 공통/프로젝트 규칙, HANDOFF.md, 요청문

### 2부. UX/UI 설계와 구현·검증 실습 (41쪽)

- 잘 쓰이는 화면: 그럴싸한 화면과 쓸 수 있는 화면, UX/UI, 사용자 흐름
- 특수교육 화면 원칙: 한 화면 한 행동, 학생별 조절, 틀렸을 때의 화면
- DESIGN.md: 화면 기준을 파일로
- 그림으로 먼저 확인하기: 그림 시안, Stitch·Claude Design, Figma
- 만들고 확인하고 공개하기: 작게 나누기, 검토와 검증, 5분 확인, GitHub Pages
- 실습: 3~5단계 생활 연습 자료 하나 완성
