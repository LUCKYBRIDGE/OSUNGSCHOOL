# OSUNGSCHOOL 핵심 지침 변경 기록

이 문서는 프로젝트의 핵심 작업 지침이 **왜 바뀌었는지**를 기록한다.

대상 파일:

- `AGENTS.md`
- `DESIGN.md`
- `CONTENT_STYLE_GUIDE.md`
- `SPEAKER_SCRIPT_GUIDE.md`

사소한 오탈자 수정은 기록하지 않아도 된다. 반복 작업에 영향을 주는 원칙·구조·기준이 바뀔 때 기록한다.

---

## 2026-09-28 - 지침 체계 2.0 정비

### 배경

초기 PPT/PDF를 반복 개선하는 과정에서 다음 문제가 계속 나타났다.

- 텍스트가 카드·도형 안에서 잘리거나 겹침
- 내용이 많아지면서 글자 크기가 작아짐
- 빈 공간을 채우려다 화면 밀도가 과도해짐
- 화면 문구와 발표 대본의 역할이 섞임
- 같은 개념의 용어가 자료마다 조금씩 달라질 가능성
- 개별 산출물은 수정되지만 반복되는 실패가 지침에 충분히 환류되지 않음

### 변경

#### `AGENTS.md`

- 프로젝트 최상위 운영 규칙으로 역할을 명확히 함
- GitHub를 단일 진실 공급원으로 지정
- ChatGPT 프로젝트 소스는 작업용 참조본으로 운영하도록 정의
- 작업 유형별 필수 확인 순서 추가
- Review와 Verification 구분 추가
- 반복 문제를 지침으로 환류하는 `지침 개선 루프` 추가
- 지침 변경 시 중복·충돌을 피하는 원칙 추가

#### `DESIGN.md`

- 버전 2.0으로 개편
- 빈 공간을 디자인 요소로 명문화
- 자동 글자 축소 의존 금지
- 레이아웃 선택 기준 추가
- 카드·표·프로세스별 공간·텍스트 한계 추가
- overflow 대응 순서를 명문화
- 생성 전 사전 점검과 반복 문제 환류 절차 추가

#### `CONTENT_STYLE_GUIDE.md`

- 슬라이드 제목·본문·카드·표·도식의 문구 기준 분리
- 요소별 텍스트 예산 정의
- Harness, Loop, Graph, Agent, Skill, Hook, MCP 등 표준 용어 정의
- 화면과 발표 대본의 역할 구분
- 공간이 부족할 때 콘텐츠를 줄이는 순서 정의

#### `SPEAKER_SCRIPT_GUIDE.md`

- 발표 대본을 슬라이드 낭독문과 분리
- 슬라이드 유형별 설명 방식 정의
- 비유 → 실제 개념 → 실제 사례 흐름 정의
- 특수교육 맥락 연결 기준 추가
- 중복 설명·과도한 대본 길이 관리 기준 추가
- `[질문]`, `[시연]`, `[전환]`, `[주의]`, `[예시]` 강사용 메모 표기 정의

### 운영 원칙

앞으로 반복되는 문제가 발견되면 현재 산출물만 고치지 않고 해당 원인이 속한 지침 파일을 함께 검토한다.

GitHub 핵심 지침이 변경되면 ChatGPT 프로젝트 소스로 등록된 사본도 가능한 한 최신본으로 교체한다.
