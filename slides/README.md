# slides

강의용 편집 원본과 최종 발표 PDF를 분리해 관리한다.

```text
slides/
├─ source/
│  └─ osung_ai_vibecoding_lecture_v1.pptx
└─ pdf/
   └─ osung_ai_vibecoding_lecture_v1.pdf
```

## 원칙

- 원본 수정 전 `../DESIGN.md`를 먼저 확인한다.
- 화면 비율은 16:9를 유지한다.
- PDF 생성 후 전 페이지 렌더링 검수를 수행한다.
- 최종본만 `pdf/`에 둔다.
- 새 버전은 기존 파일을 덮어쓰기보다 `v2`, `v3`처럼 버전을 올린다.
